# Teto Engine

## Description
TetoEngine is a small engine I used for my final project in uni for a demo of a game named "Scopalatro"

This engine is still in developpement and the game too

## Dependencies

- Freetype
- glm
- GLFW3


## Build

```shell
mkdir build
```

```shell
cmake -B build -S .
```

```shell
cd build
```

```shell
cmake --build .
```

you can install it too !

```shell
cmake --build . --target install
```
